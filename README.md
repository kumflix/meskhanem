# Meşkhanem (@mesk.hanem) — Web Sitesi Kurulum ve Yayınlama Rehberi

Bu klasör, **Meşkhanem** için özel olarak tasarlanmış, tamamen duyarlı (responsive), bağımsız e-kitap kütüphanesi ve e-ticaret web sitesini içerir.

## Özellikler
- **8 E-Kitap ve 8'li Koleksiyon Seti**: Fiyatlar, kapaklar, içindekiler ve detaylı inceleme pencereleri (Modal).
- **Dinamik Alışveriş Sepeti**: Sepete ekleme, çıkarma, anlık toplam tutar hesaplama.
- **Doğrudan FAST / Havale & WhatsApp Sipariş Akışı**: Komisyonsuz, doğrudan IBAN üzerinden ödeme alma ve otomatik teslimat yönlendirmesi.
- **Mistik & Tasavvufi Tasarım**: Gece mavisi zemin, altın varak detaylar, Rumi alıntıları ve ambient müzik çalar arayüzü.
- **Mobil ve Masaüstü Tam Uyumlu**: Sıfır ek kütüphane bağımlılığı ile tek dosya halinde tüm tarayıcılarda çalışır.

## Nasıl Yayınlayabilirsiniz? (Ücretsiz & Hızlı Yöntemler)

### 1. Yöntem: Vercel veya Netlify (Önerilen — 2 Dakikada Canlıda)
1. [vercel.com](https://vercel.com) veya [netlify.com](https://netlify.com) adresine gidin.
2. `meskhanem_website` klasörünü (veya `index.html` dosyasını) sürükleyip bırakın.
3. Siteniz anında `meskhanem.vercel.app` şeklinde ücretsiz SSL sertifikalı olarak yayına girer. İsterseniz kendi özel alan adınızı (domain) tek tıkla bağlayabilirsiniz.

### 2. Yöntem: GitHub Pages
1. GitHub üzerinde `meskhanem` adında bir repository açın.
2. `index.html` dosyasını yükleyin ve Ayarlar > Pages bölümünden yayına alın.

### 3. Yöntem: Kendi Hosting / cPanel / BulutPress Sunucunuz
1. Hosting kontrol panelinizdeki `public_html` klasörüne `index.html` dosyasını yükleyin.
